# Public CI burst failure

2026-10-09 local date. Expanded [CI run 38014892588](https://github.com/Ikteder/resumeprobe/actions/runs/38014892588)
failed Ubuntu Python 3.12's concurrent HTTP test while the other five jobs passed.
112 tests passed in the failed job, with one assertion indexing a missing status.
The client can truthfully return a transport error, so the assertion now includes the
entire result set when failing. The private server now sets accept backlog 64 before
listening, not after construction. No client timeout increased, retry added, or unsafe
result hidden. A larger burst independently exercises 32 calls with 16 threads.

The default backlog is a plausible congestion cause; the old log does not prove the
precise socket error. Cross-platform CI is required to establish regression behavior.

Local full suite: 114 passed in 118.25 seconds, Ruff and Git whitespace passed.
Two concurrency tests repeated five times: 10/10 passed, per-run times 2.95, 3.50,
2.98, 2.19, and 2.14 seconds. An initial repeat command used unavailable pytest-repeat
`--count`; it failed argument parsing and ran no tests. Used a PowerShell loop instead,
without adding a dependency. The full suite ran alongside some repeated burst tests,
so its elapsed time is not a comparable performance benchmark.

Corrected public CI38015371793 passed all six Ubuntu/Windows Python3.11/3.12/3.14
jobs at commit2c57645. This verifies the regression fix on the supported matrix,
not a universal causal proof or server load/performance guarantee.

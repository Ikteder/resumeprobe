# Asset and Evidence Provenance

Date: 2026-10-09

`docs/assets/recovery-v1.svg` is generated by the repository's `render_svg` from the measured
90-case report. Labels and bar lengths reflect observed effect counts after the after-effect
crash. Source code and synthetic fixture are MIT. No stock image, company artwork, external
dataset, or AI-generated bitmap is included.

The JSON/HTML/SVG report files are generated by the CLI. The README uses a portable relative
image link. SVG XML validity, deterministic rendering from the saved report, and browser
layout are part of verification. Process IDs and latencies are evidence, not seed-stable values.

## HTTP replay comparison

`docs/assets/http-replay-v1.svg` is generated from independently re-audited
`docs/experiments/http-replay-v1.json` using `scripts/export_evidence.py --http`.
Bars show observed committed effect counts after actual lost HTTP responses; labels
include all three repetitions. No AI raster generation or third-party art. MIT.

## Sink transaction comparison

`docs/assets/sink-atomicity-v1.svg` is generated from re-audited
`docs/experiments/sink-atomicity-v1.json` with `scripts/export_evidence.py --sink`.

with a clearly labeled split-commit fixture. Independently authored MIT SVG, no external art.

## Impact gate

Real user: AI application engineer shipping a tool with effects. Costly problem: resumed agents can silently repeat writes while appearing successful. Evidence: explicit runtime documentation and current issue reports. Original value: real process crash injection plus an effect-count/result identity audit, with reproducible comparisons and portable traces. Measurable: matrix expectations, observed effects, first divergent boundary, completion-only false-safe count. Finishable: one tool, two adapters, five boundaries, three modes, bounded subprocesses. Maintainable: standard-library supervisor/sink and optional pinned framework integration. License: independent MIT, no upstream code reuse.

Cognee is not an integration candidate for this slice: this tests effect/checkpoint recovery, not knowledge ingestion, retrieval, or semantic memory. Its memory-integrity direction remains in the portfolio backlog.
